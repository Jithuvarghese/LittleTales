# LittleTales

A colourful, safe, joyful website where children aged 3–7 listen to stories, play gentle
quizzes, meet letters and numbers, and sing along to rhymes. No ads, no accounts, no trackers;
all progress stays on the device.

## Getting started

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests
npm run lint
npm run typecheck
npm run build      # production build into dist/
```
